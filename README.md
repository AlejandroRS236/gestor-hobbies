# Gestor de hobbies

Aplicación de escritorio personal para gestionar en un solo sitio mis hobbies: figuras/coleccionismo, anime, lectura y videojuegos.

> Proyecto en construcción. La visión completa y las decisiones de diseño están en [docs/vision.md](docs/vision.md).

## Tecnología prevista

- **core**: Java + Spring Boot (modelo, servicios, persistencia, scraping con Playwright)
- **api**: Spring Boot REST
- **frontend**: React + Vite + TypeScript
- **desktop**: Electron (ventana, arranque del backend e instalador)
- **Base de datos**: PostgreSQL en Supabase, compartida entre equipos
